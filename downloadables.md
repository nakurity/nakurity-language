# Nakurity Lang Modules

This file lists downloadable modules for different components of the Nakurity language system.
Its to be in the github release of the program's specific version.

## needy/recommended

These are the essential modules for basic functionality.

- parser (https://raw.githubusercontent.com/user/repo/prototype-dev:1.0.0/static/.needy/modules/parser.py) -> static/.needy/modules/parser.py  
- tokenizer (https://raw.githubusercontent.com/user/repo/prototype-dev:1.0.0/static/.needy/modules/tokenizer.py) -> static/.needy/modules/tokenizer.py

## needy/all

## Notes
